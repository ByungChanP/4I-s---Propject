|:-------------------|:----------------|:----------------|:----|:-----|:----------------------------------------------------------------------------|
| REQ-USER-01        | 회원              | 회원가입            | 박병찬 | 1순위  | 이메일, 비밀번호, 닉네임 입력 받아 member DB 테이블에 저장                                      |

| REQ-USER-04        | 회원              | 회원의 게임 정보 작성/조회 | 박병찬 | 3순위  | 자신의 게임 정보(예 : LOL이라면 자신의 레벨, 티어, 포지션 등)을 작성/조회                              |

| REQ-POST_LIST-02   | 파티 모집 게시글 목록    | 파티 모집 게시글 목록 조회 | 임민교 | 1순위  | 전체 질문 게시글 목록 표시 및 상세 이동                                                     |
| REQ-POST_LIST-03   | 파티 모집 게시글 목록    | 파티 모집 게시글 필터링   | 임민교 | 2순위  | 전체 게시글 / 모집중인 게시글 / 마감된 게시글 별로 목록 조회                                        |
| REQ-POST_LIST-04   | 파티 모집 게시글 목록    | 파티 모집 게시글 검색    | 임민교 | 3순위  | 목록에서 게시글 키워드 검색                                                             |
| REQ-POST_WRITE-01  | 파티 모집 게시글 등록/수정 | 파티 모집 게시글 등록    | 최승혁 | 1순위  | 게시글 작성하여 post 테이블에 insert. 작성 시 모집 유형, 파티 모집 인원, 모집 조건, 제목, 내용, 모집 마감 시간 포함 |
| REQ-POST_WRITE-02  | 파티 모집 게시글 등록/수정 | 파티 모집 게시글 수정    | 최승혁 | 1순위  | 게시글 작성하여 post 테이블에 update. 모집 유형, 파티 모집 인원, 모집 조건, 제목, 내용, 모집 마감 시간 수정 가능   |
| REQ-POST_DETAIL-01 | 파티 모집 게시글 상세정보  | 게시글 상세정보 조회     | 김병호 | 1순위  | 게시글 내용, 모집 조건, 현재 파티원 목록 조회                                                 |
| REQ-POST_DETAIL-02 | 파티 모집 게시글 상세정보  | 파티 참가 신청        | 김병호 | 1순위  | 게시글 상세보기 화면에서 파티 참가 신청 버튼을 눌러 신청                                            |
| REQ-POST_DETAIL-03 | 파티 모집 게시글 상세정보  | 파티 모집 마감으로 전환   | 김병호 | 2순위  | 모집 기간이 지나거나, 파티장이 모집 마감 버튼을 누르면 게시글이 마감 상태로 전환되어 더이상 신청할 수 없음               |
| REQ-POST_DETAIL-04 | 파티 모집 게시글 상세정보  | 제한 조건 충족 여부 검증  | 김병호 | 3순위  | 파티 신청자의 게임 정보가 파티 모집 조건을 충족하는지 검증                                           |
