## 1.1 요구사항 기능 명세 표

| 요구사항 ID      | 구분        | 기능명             | 담당자 | 우선순위 | 상세 내용                                                            |
|:-------------|:----------|:----------------|:----|:-----|:-----------------------------------------------------------------|
| REQ-USER-01  | 회원        | 회원가입            | 김병호 | 1순위  | 이메일, 비밀번호, 이름, 전화번호 입력 받아 member DB 테이블에 저장                      |
| REQ-USER-02  | 회원        | 로그인/로그아웃        | 김병호 | 1순위  | 이메일/비밀번호 DB 검증 후 HttpSession 생성 및 파기                             |
| REQ-USER-03  | 회원        | 프로필 정보 조회       | 김병호 | 2순위  | 자신의 이메일, 비밀번호, 닉네임을 member 테이블에서 찾아 조회                           |
| REQ-USER-04  | 회원        | 게시글, 댓글 조회      | 김병호 | 3순위  | 자신이 작성한 게시글 제목과 댓글을 각각 post, reply테이블에서 찾아 조회                    |
| REQ-USER-05  | 회원        | 회원의 게임 정보 작성/조회 | 김병호 | 3순위  | 자신의 게임 정보(예 : LOL이라면 자신의 레벨, 티어, 포지션 등)을 작성/조회                   |
| REQ-INDEX-01 | 인덱스       | 게임 게시판 목록 조회    | 박병찬 | 2순위  | 게임 종류별로 게시판을 조회하고 사용자는 파티를 찾고자 하는 게임을 선택                         |
| REQ-POST-01  | 파티 모집 게시글 | 파티 모집 게시글 목록 조회 | 박병찬 | 1순위  | 전체 질문 게시글 목록 표시 및 상세 이동                                          |
| REQ-POST-02  | 파티 모집 게시글 | 파티 모집 게시글 작성    | 박병찬 | 1순위  | 작성 시 모집 유형, 파티 모집 인원, 제목, 내용 포함                                  |
| REQ-POST-03  | 파티 모집 게시글 | 파티 모집 게시글 수정/삭제 | 박병찬 | 1순위  | 질문 상세 내용 및 등록된 답변 댓글(reply) 목록 함께 표시, 조회수 증가                     |
| REQ-POST-04  | 파티 모집 게시글 | 페이징 및 키워드 검색    | 임민교 | 2순위  | 게시글 목록 페이지당 10개 페이징 처리 및 질문 제목/내용 검색 기능                          |
| REQ-POST-05  | 파티 모집 게시글 | 현재 파티 참여 인원 조회  | 임민교 | 2순위  | 현재 파티에 참여한 인원을 조회                                                |
| REQ-POST-06  | 파티 모집 게시글 | 파티 모집 마감으로 전환   | 임민교 | 2순위  | 정원이 다 채워지거나, 파티장이 모집 마감 버튼을 누르면 게시글이 마감 상태로 전환되어 더이상 댓글을 남길 수 없음 |
| REQ-POST-07  | 파티 모집 게시글 | 파티 모집중 여부 조회    | 임민교 | 2순위  | 파티 모집중인지 마감되었는지 여부를 목록에서 조회                                      |
| REQ-POST-08  | 파티 모집 게시글 | 게임 시작 시간 설정     | 최승혁 | 3순위  | 글 등록 시 자신이 희망하는 게임 시작 시간을 게시하고, 파티원끼리 약속된 시간에 만날 수 있도록 함         |
| REQ-POST-09  | 파티 모집 게시글 | 파티 모집 유형 설정     | 최승혁 | 3순위  | 글 등록 시 자신이 가려고 하는 파티의 종류(예 : 랭크/일반, 보스 종류)를 선택                   |
| REQ-REPLY-01 | 댓글        | 파티 참여 신청        | 최승혁 | 1순위  | 회원 본인이 원하는 파티의 게시글에 댓글을 남겨 파티 가입 신청                              |
| REQ-REPLY-02 | 댓글        | 파티 참여 신청 취소     | 최승혁 | 2순위  | 회원 본인이 신청한 파티 가입 취소                                              |
| REQ-REPLY-03 | 댓글        | 파티 참여 수락        | 최승혁 | 2순위  | 게시글 작성자가 파티 신청자의 파티 가입 여부를 수락/거절                                 | |
