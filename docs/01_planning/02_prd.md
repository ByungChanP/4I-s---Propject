## 1.1 요구사항 기능 명세 표

| 요구사항 ID      | 구분  | 기능명            | 담당자 | 우선순위 | 상세 내용 |
|:-------------|:----|:---------------|:----|:-----| :--- |
| REQ-USER-01  | 회원  | 회원가입           | 김병호 | 1순위  | 이메일, 비밀번호, 이름, 전화번호 입력 받아 member DB 테이블에 저장 |
| REQ-USER-02  | 회원  | 로그인/로그아웃       | 김병호 | 1순위  | 이메일/비밀번호 DB 검증 후 HttpSession 생성 및 파기 |
| REQ-USER-03  | 회원  | 프로필 정보 조회      | 김병호 | 2순위  | 자신의 이메일, 비밀번호, 닉네임, 전화번호를 member 테이블에서 찾아 조회 |
| REQ-USER-04  | 회원  | 게시글, 댓글 조회     | 김병호 | 3순위  | 자신이 작성한 게시글 제목과 댓글을 각각 post, reply테이블에서 찾아 조회 |
| REQ-POST-01  | 게시글 | 질문 목록 조회       | 박병찬 | 1순위  | 전체 질문 게시글 목록 표시 및 상세 이동 (post 테이블 조회) |
| REQ-POST-02  | 게시글 | 질문 게시글 작성      | 박병찬 | 1순위  | 로그인 세션 유효 시 기술 질문 제목과 본문 입력받아 등록 |
| REQ-POST-03  | 게시글 | 질문 상세 조회       | 박병찬 | 1순위  | 질문 상세 내용 및 등록된 답변 댓글(reply) 목록 함께 표시, 조회수 증가 |
| REQ-POST-04  | 게시글 | 페이징 및 키워드 검색   | 임민교 | 2순위  | 게시글 목록 페이지당 10개 페이징 처리 및 질문 제목/내용 검색 기능 |
| REQ-POST-05  | 게시글 | 게시글 정렬         | 임민교 | 2순위  | 게시글 최신 순, 조회수 순, 댓글 순으로 정렬                                        |
| REQ-POST-06  | 게시글 | 익명 에러 질문 작성/삭제 | 임민교 | 3순위  | 비로그인 상태에서 비밀번호 입력 후 질문 등록, 삭제 시 비밀번호 확인 검증 |
| REQ-POST-07  | 게시글 | 카테고리별 게시글 등록   | 임민교 | 3순위  | 게시물 등록 시 잡담, 게임 정보 공유 등 카테고리를 선택할 수 있도록 하고, 카테고리별로 게시물을 조회  |
| REQ-REPLY-01 | 댓글  | 답변 댓글 작성       | 최승혁 | 2순위  | 질문 상세 페이지 하단 폼에서 답변 내용 입력 및 reply 테이블 저장 |
| REQ-REPLY-02 | 댓글  | 답변 댓글 삭제       | 최승혁 | 2순위  | 본인 작성 답변 댓글 세션 확인 후 삭제 처리 |
| REQ-REPLY-03 | 댓글  | 답변 댓글 수정       | 최승혁 | 3순위  | 본인 작성 답변 댓글 세션 확인 후 내용 수정 폼 제공 및 반영 |
| REQ-REPLY-04 | 댓글  | 대댓글 기능         | 최승혁 | 3순위  | 대댓글 기능 추가 |
