## 1.1 요구사항 기능 명세 표

| 요구사항 ID            | 구분              | 기능명               | 담당자 | 우선순위 | 상세 내용                                                                             |
|:-------------------|:----------------|:------------------|:----|:-----|:----------------------------------------------------------------------------------|
| REQ-AUTH-01        | 인증              | 로그인 사용자 인증        | 박병찬 | 1순위  | 로그인한 사용자만 이용가능하도록 HttpSession 통해 인증                                               |
| REQ-AUTH-02        | 인증              | 세션관리              | 박병찬 | 1순위  | 로그인 성공시 세션 생성하고 로그아웃시 세션을 삭제                                                      
| REQ-USER-01        | 회원              | 회원가입              | 박병찬 | 1순위  | 이메일, 비밀번호, 닉네임 입력 받아 member DB 테이블에 저장                                            |
| REQ-USER-02        | 회원              | 로그인/로그아웃          | 박병찬 | 1순위  | 이메일/비밀번호 DB 검증 후 HttpSession 생성 및 파기                                              |
| REQ-USER-03        | 회원              | 프로필 정보 조회         | 박병찬 | 2순위  | 자신의 이메일, 비밀번호, 닉네임을 member 테이블에서 찾아 조회                                            |
| REQ-USER-04        | 회원              | 회원의 게임 정보 작성      | 박병찬 | 3순위  | 자신의 게임 정보(예 : LOL이라면 자신의 레벨, 티어, 포지션 등)을 작성/조회                                    |
| REQ-POST_LIST-01   | 파티 모집 게시글 목록    | 게임 게시판 목록 조회      | 임민교 | 1순위  | 게임 종류별로 게시판을 조회하고 사용자는 파티를 찾고자 하는 게임을 선택                                          |
| REQ-POST_LIST-02   | 파티 모집 게시글 목록    | 파티 모집 게시글 목록 조회   | 임민교 | 1순위  | 전체 파티 게시글 목록 표시 및 파티 모집 상세 페이지로 이동                                                |
| REQ-POST_LIST-03   | 파티 모집 게시글 목록    | 파티 모집 게시글 필터링     | 임민교 | 2순위  | 전체 게시글 / 모집중인 게시글 / 마감된 게시글 별로 목록 조회                                              |
| REQ-POST_LIST-04   | 파티 모집 게시글 목록    | 파티 모집 게시글 검색      | 임민교 | 3순위  | 키워드 검색기능을 추가하여 파티 게시글을 검색                                                         |
| REQ-POST_WRITE-01  | 파티 모집 게시글 등록/수정 | 파티 모집 게시글 등록      | 최승혁 | 1순위  | 파티 모집 게시글 작성하여 post 테이블에 insert. 작성 시 모집 유형, 파티 모집 인원, 모집 조건, 제목, 내용, 모집 마감 시간 포함 |
| REQ-POST_WRITE-02  | 파티 모집 게시글 등록/수정 | 파티 모집 게시글 수정      | 최승혁 | 1순위  | 파티 모집 게시글 작성하여 post 테이블에 update. 모집 유형, 파티 모집 인원, 모집 조건, 제목, 내용, 모집 마감 시간 수정 가능   |
| REQ-POST_WRITE-03  | 파티 모집 게시글 삭제    | 파티 모집 게시글 삭제      | 최승혁 | 2순위  | 파티 모집 게시글 작성자가 자신이 작성한 게시글 삭제. post 테이블에서 delete                                  |
| REQ-POST_DETAIL-01 | 파티 모집 게시글 상세정보  | 파티 모집 게시글 상세정보 조회 | 김병호 | 1순위  | 게시글 내용, 모집 조건, 현재 파티원 목록 조회                                                       |
| REQ-POST_DETAIL-02 | 파티 모집 게시글 상세정보  | 파티 참가 신청          | 김병호 | 1순위  | 파티 모집 상세페이지 화면에서 파티 참가 신청 버튼을 눌러 신청                                               |
| REQ-POST_DETAIL-03 | 파티 모집 게시글 상세정보  | 파티 모집 마감으로 전환     | 김병호 | 2순위  | 모집 기간이 지나거나, 파티장이 모집 마감 버튼을 누르면 게시글이 마감 상태로 전환되어 더이상 신청할 수 없음                     |
| REQ-POST_DETAIL-04 | 파티 모집 게시글 상세정보  | 제한 조건 충족 여부 검증    | 김병호 | 3순위  | 파티 신청자의 게임 정보가 파티 모집 조건을 충족하는지 검증                                                 |
| REQ-PROFILE-01     | 인게임 프로필         | 인게임 정보 등록 / 수정    | 임민교 | 1순위  | 유저가 프로필 화면에서 정보를 입력하는 페이지 제공 (게임마다 입력 column이 달라 json 형태로 저장)                     |
| REQ-PROFILE-02     | 인게임 프로필         | 인게임 정보 조회         | 임민교 | 2순위  | 파티 모집 완료시 호스트가 참여자의 인게임 정보를 확인하도록 조회                                              |
