## 1.1 기획 개요

### 1.1.1 프로젝트 배경 및 목적
게임을 플레이하는 사용자들은 파티를 모집하기 위해 커뮤니티 게시판이나 메신저를 이용하는 경우가 많아 모집 현황을 확인하거나 적합한 파티를 찾는데 에러사항이 있음
이번 프로젝트를 통해 게임별 파티 모집 게시판과 참가자의 계정 정보를 호스트에게 제공하여 손쉽게 파티를 모집할 수 있는 서비스를 구현하고자 함

### 1.1.2 서비스 주요 특징

- 회원가입 및 HttpSession 기반 로그인/로그아웃 세션 인증 처리
- 파티모집 게시글 작성, 상세 조회, 수정, 삭제(CRUD) 지원
- 서버 사이드 렌더링(Thymeleaf) 동적 뷰 제공
- 게임 프로필 등록(티어, 레벨, 직업 등) 호스트 제공
- 현재 모집 인원 및 최대 인원 관리

## 1.2 주요 기능 요구사항

### 1.2.1 회원 관리 기능
- 회원가입  (이메일,비밀번호,닉네임,가입날짜)
- 회원탈퇴  (게시글 삭제 유무 선택)
- 로그인 및 로그아웃 (HttpSession 세션 생성 및 파기)
- 회원 정보 조회,수정 (이메일 변경 허용, 중복 금지)
- 게임별 프로필 관리 기능

### 1.2.2 게임 관리 기능
- 게임 목록 조회 (클릭시 해당 게시판 이동)
- 게임별 게시판 제공
- 게임 설명 및 대표 이미지 제공

### 1.2.3 파티 모집 게시글 기능
- 모집 제목, 인원, 카테고리(랭크, 일반) 표시
- 현재 참여 인원 표시
- 모집 상태 표시(모집중, 마감)
- 글쓰기 기능 

### 1.2.4 파티 게시글 글쓰기 기능
- 모집 유형, 인원 설정 기능
- 파티 모집 마감 시간 설정 기능
- 게시글 제목, 내용 작성 기능

### 1.2.5 파티 참여 기능
- 게임 참여시 유저 프로필 정보 표시
- 현재 파티 모집 인원 증가
- 모집 인원 달성, 마감 시간 만료시 비공개 처리

## 1.3 팀 구성 및 도메인별 역할 분담

### 1.3.1 팀명 및 역할 분담표 (팀명: 4I's(포아이즈))

| 이름 | 직책 | 담당 도메인 | 세부 구현 내용 |
| :--- | :--- | :--- | :--- |
| 박병찬 | 팀장 | 게시글관리 | 게시글 목록/상세/조회/작성/수정/삭제 |
| 최승혁 | 팀원 | 댓글관리 | 답변 댓글/대댓글 조회/작성/삭제, 댓글/대댓글 수정 |
| 김병호 | 팀원 | 회원관리 | 회원가입, 로그인/로그아웃, 마이페이지  |
| 임민교 | 팀원 | 게시글관리 | 페이징 및 검색, 카테고리 선택  |

### 1.3.2 역할 분담 원칙
- 모든 팀원이 특정 기술 레이어에 치우치지 않고, 각자 맡은 도메인에 대해 화면(UI)부터 DB 처리까지 수직 슬라이스 형태로 구현.
- 모든 기능은 개인 브랜치에서 개발 후 Pull Request를 통해 코드 리뷰를 거쳐 develop 브랜치에 병합한다.

### 1.3.3 팀원별 도메인 담당 정의
#### 1) 박병찬 (팀장)
- 총괄 역할: 프로젝트 초기 환경 구성, Git/GitHub Projects 체계 수립
- 담당 도메인: 게시글 관리 기능 (질문 게시글 목록, 상세 조회, 작성, 수정, 삭제)

#### 2) 최승혁 (팀원)
- 담당 도메인: 댓글 관리 기능(답변 댓글/대댓글 작성, 삭제 및 수정)

#### 3) 김병호 (팀원)
- 담당 도메인: 회원 관리 기능 (회원가입, 로그인/로그아웃, 마이페이지)

#### 3) 임민교 (팀원)
- 담당 도메인: 게시글 관리 기능 (페이징 및 검색, 익명 질문 관리, 카테고리 조회)
