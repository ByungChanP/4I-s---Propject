## 1.1 기획 개요

### 1.1.1 프로젝트 배경 및 목적
유저가 한곳에서 게임 공략과 팁을 쉽고 빠르게 찾을 수 있는 환경 제공,질문/답변(Q&A), 파티 모집, 자유 소통이 가능한 건강한 게임 게이머 생태계 조성

### 1.1.2 서비스 주요 특징
- 회원가입 및 HttpSession 기반 로그인/로그아웃 세션 인증 처리
- 기술 질문 게시글 작성, 상세 조회, 수정, 삭제(CRUD) 지원
- 답변 댓글 작성, 삭제, 수정 기능 및 서버 사이드 렌더링(Thymeleaf) 동적 뷰 제공

---

## 1.2 주요 기능 요구사항

### 1.2.1 회원 관리 기능
- 회원가입  (id,비밀번호,닉네임,가입날짜,이메일(선택),전화번호(선택))
- 회원탈퇴(게시글 및 댓글 삭제 유무 선택)
- 로그인 및 로그아웃 (HttpSession 세션 생성 및 파기)
- 회원 정보 조회,수정
- 관리자 계정 권한 부여(회원 차단/게시물 삭제)

### 1.2.2 게시글 관리 기능
- 게시글 목록 조회(페이징 및 키워드 검색 포함)
- 게시글 최신 순, 조회수 순, 댓글 순으로 정렬
- 게시글 상세 보기(조회수 증가 처리)
- 게시글 작성, 수정, 삭제(본인 작성 글 제어)
- 비회원 익명 질문 작성 및 비밀번호 검증 삭제

### 1.2.3 답변 댓글 관리 기능
- 게시글 상세 화면 내 답변 댓글,대댓글 작성
- 답변 댓글,대댓글 목록 조회 및 댓글,대댓글 삭제/수정

## 1.3 팀 구성 및 도메인별 역할 분담

### 1.3.1 팀명 및 역할 분담표 (팀명: 4I's(포아이즈))

| 이름 | 직책 | 담당 도메인 | 세부 구현 내용 |
| :--- | :--- | :--- | :--- |
| 박병찬 | 팀장 | 게시글관리 | 게시글 목록/상세/조회/작성/수정/삭제 |
| 최승혁 | 팀원 | 댓글관리 | 답변 댓글/대댓글 조회/작성/삭제, 댓글/대댓글 수정 |
| 김병호 | 팀원 | 회원관리 | 회원가입, 로그인/로그아웃, 마이페이지, HandlerInterceptor 세션 검증 |
| 임민교 | 팀원 | 게시글관리 | 페이징 및 검색, 익명 게시글 관리, 카테고리 선택  |

### 1.3.2 역할 분담 원칙
- 모든 팀원이 특정 기술 레이어에 치우치지 않고, 각자 맡은 도메인에 대해 화면(UI)부터 DB 처리까지 수직 슬라이스 형태로 구현.
- 모든 기능은 개인 브랜치에서 개발 후 Pull Request를 통해 코드 리뷰를 거쳐 develop 브랜치에 병합한다.

### 1.3.3 팀원별 도메인 담당 정의
#### 1) 박병찬 (팀장)
- 총괄 역할: 프로젝트 초기 환경 구성, Git/GitHub Projects 체계 수립
- 담당 도메인: 게시글 관리 기능 (질문 게시글 목록, 상세 조회, 작성, 수정, 삭제)

#### 2) 최승혁 (팀원)
- 담당 도메인: 댓글 관리 기능(답변 댓글/대댓글 작성, 삭제 및 수정)

#### 3) 김병호 (팀원)
- 담당 도메인: 회원 관리 기능 (회원가입, 로그인/로그아웃, 마이페이지)

#### 3) 임민교 (팀원)
- 담당 도메인: 게시글 관리 기능 (페이징 및 검색, 익명 질문 관리, 카테고리 조회)
